# T-ID iOS: временное зеркало CocoaPods

Снимок установленных пакетов, восстановленный из кеша CocoaPods для сборок
при недоступности `opensource.tbank.ru`.

| Pod | Версия | Содержимое |
| --- | --- | --- |
| `T-ID` | `2.0.3` | Swift-исходники и ресурсы |
| `TSSLPinningPublic` | `11.14.0` | XCFramework для iPhone и симулятора |

Оба пакета подключаются из этого репозитория:

```ruby
tid_mirror = 'https://github.com/amf0154/TinkoffID-iOS.git'
tid_snapshot = 'cache-2.0.3-11.14.0'

pod 'T-ID', :git => tid_mirror, :tag => tid_snapshot
pod 'TSSLPinningPublic', :git => tid_mirror, :tag => tid_snapshot
```

Для воспроизводимой сборки можно заменить `:tag` на `:commit` с SHA этого
снимка. После переключения источников нужно обновить `Podfile.lock`.
Зависимость `TrustKit` устанавливается отдельно обычным способом CocoaPods.

Исходники, бинарники, ресурсы и лицензии пакетов сохранены без изменений.
Корневые podspec адаптированы для размещения двух пакетов в одном репозитории.
Сведения об исходных источниках и контрольных суммах — в `RECOVERY-NOTES.txt`.
История Git официальных репозиториев в этот снимок не входит.

Если Bitrise запускает `scripts/setup_trusted_certs.sh` из репозитория приложения,
после подключения обоих пакетов к зеркалу задайте для этого шага
`SKIP_NETWORK_CHECK=1`. Это пропускает проверку доступности прежнего
Git-репозитория; проверка TLS-сертификатов остаётся включённой.
